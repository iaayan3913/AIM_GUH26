## Running it
```
cd sync && npm install && npm run seed
cd ../ui && npm install && npm start        # http://localhost:3000 (use localhost, not 127.0.0.1)
```
Env: `FOBE_AI=real|mock` (default auto), `FOBE_USE_CACHE=1`, `FOBE_P2P=0`, `FOBE_NO_AUTH=1` (emergency only), `FOBE_DB_PASSPHRASE` (same as sync), `PORT`.
First run: open `#/login`, type your name, tap the YubiKey to register it.
